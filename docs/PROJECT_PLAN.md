# Project plan

ThermalGuard will deliver a working regression project and a submission report. Slides and viva preparation are handled by another teammate.

## Deliverables

- reproducible dataset checks and preprocessing;
- exploratory analysis;
- group-aware model comparison;
- final test evaluation;
- engineering error analysis and model explanation;
- saved inference pipeline;
- Streamlit prediction application;
- automated tests;
- complete README; and
- submission report with cited results and diagrams.

## Delivery order

1. Establish the repository and data contract.
2. Add dataset validation and preprocessing.
3. Complete exploratory analysis.
4. Train and compare regression models.
5. Evaluate errors and explain the selected model.
6. Build the Streamlit application.
7. Test the workflow in a clean environment.
8. Write and verify the submission report.

Each milestone is committed after its observable behaviour is checked.

## Completion rule

The project is complete when a clean environment can follow the README, reproduce the reported results, run the tests, and launch the application using the saved model pipeline.
