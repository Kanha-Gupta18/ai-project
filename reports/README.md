# Reports and generated results

This directory contains the recorded experiment results and the generated figures, tables, and metrics used to support them. The repository keeps these files so the evaluation evidence can be inspected without retraining the model.

Running the analysis and training scripts refreshes the generated files. Numerical values in the submission report must come from these outputs.

The final written submission is available as an editable Markdown source and a formatted Word document:

- `SUBMISSION_REPORT.md`
- `ThermalGuard_Submission_Report.docx`
